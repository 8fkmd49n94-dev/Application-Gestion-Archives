# Application Web de Gestion des Archives

## Présentation

Projet réalisé dans le cadre d'un stage de fin d'année chez Ménara Holding (Juillet – Août 2024).

Conception et développement d'une application web destinée à faciliter la gestion et le suivi des archives.

## Fonctionnalités principales

- Gestion et suivi des archives.
- Centralisation des informations relatives aux archives.
- Notifications par e-mail pour faciliter le suivi des archives.

## Technologies utilisées

- **Backend :** Java, Spring Boot
- **Frontend :** React.js, Material-UI
- **Base de données :** MySQL

## Contexte du projet

Ce projet a été réalisé dans le cadre d'une expérience professionnelle chez Ménara Holding.
